Modern DOM APIs – Demo

ตัวอย่าง API ใหม่ ๆ ของ DOM ใช้สอนได้ในหน้าเดียว

1. IntersectionObserver – เช็คว่า element เข้าหน้าจอหรือยัง

เลื่อนลงมาจนกล่องด้านล่างเข้าหน้าจอ กล่องจะค่อย ๆ โผล่ขึ้นมา (animate in)

👋 ผมถูกแสดงตอนที่เข้า viewport ด้วย IntersectionObserver

2. ResizeObserver – เช็คเมื่อขนาด element เปลี่ยน

ลองลากมุมกล่อง (resize) แล้วดูค่าขนาดด้านล่าง

ลากมุมล่างขวาเพื่อเปลี่ยนขนาดกล่องนี้

3. MutationObserver – สังเกตการเปลี่ยน DOM

คลิกปุ่มเพื่อเปลี่ยนข้อความ / attribute แล้วดู log ด้านล่าง

ข้อความเริ่มต้น

(ยังไม่มีการเปลี่ยนแปลง)

4. Clipboard API – คัดลอก/วาง ข้อความ

ต้องรันบน http:// หรือ https:// (บาง browser ไม่ให้ใช้ clipboard บน file://)



5. Fullscreen API – สลับ element เข้า/ออก fullscreen

คลิกปุ่มเพื่อขยายกล่องให้เต็มหน้าจอ หรือออกจาก fullscreen

กล่องนี้จะเป็น fullscreen เมื่อตรงนี้หรือปุ่มด้านล่างถูกคลิก

6. Page Visibility API – รู้ว่า tab ถูกซ่อนหรือเปล่า

สลับไป tab อื่น แล้วกลับมาดูข้อความด้านล่าง
